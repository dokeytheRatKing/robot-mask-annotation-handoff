## 边界和 UNKNOWN 的处理

r1 曾残留645/790的小块 mask；r2 改为 UNKNOWN。随后检查拼接发现791会接回
旧残影，r3 补644和791–819，820恢复使用已查看的原有可见香蕉 track，未重新运行
SAM2。r1、r2、r3全部保留，最终入口是 `final_manifest_r3.json`。

784 的极小疑似露出部分仍有歧义，保留 UNKNOWN。UNKNOWN 区间可能包含真实可见
目标，例如重现后的若干帧；这里优先弃权，没有把整段标成“物体确认不可见”。
这个代价必须进入后续覆盖率评估。没有自动 temporal-grounding 或 subgoal 标签。

本轮先查看29个非 seed位置，再根据错误收紧边界；645等检查点因此参与了修复。
这是开发集上的定性改进，不能把检查点通过比例报告成独立测试准确率。
没有新增人工 pixel GT，因此没有新 IoU/Dice、ID-switch rate或恢复成功率。
最终998个目标记录中，636有正 mask、362为UNKNOWN；有mask也不等于全部正确。

## Seed Bank 能否发现错误

在上述29个检查点的修复前/后共58条记录上做只读检索；仍使用冻结DINOv2、
masked crop、同camera优先、排除整个query episode。沿用相似度0.50、margin0.05，
没有调参、扩库或把检索结果应用为删除规则。

| 已查看的情况 | 现有 gate 的表现 |
|---|---|
| 9个原头部坏mask | 拒绝5个，仍放过4个香蕉/夹爪混合mask |
| 9个修复后的头部mask | 9个均通过；平均cosine从0.5612升到0.8629 |
| 5个杯架假阳性 | 全部拒绝；第1008帧cosine0.2125，原SAM confidence约0.9990 |
| 6个可见且视觉上合理的右腕香蕉mask | **全部被margin gate拒绝**，包括638/720/740/748/760/780 |

例如638的正确香蕉对桃子竞争项margin为−0.0747；720对牛油果为−0.0377。
因此 bank 对身份漂移有提示价值，却不能独立担任mask质量验收或删除条件。
头部混合mask可能保留足够香蕉外观而通过；小尺度腕部香蕉的正确mask又可能
检索到更相似的其他水果。增加或减少一个全局阈值都无法同时解决这两类问题。

下一步如补bank，应仅补远距离/部分遮挡腕部香蕉与混淆水果的对照视角，先复用
已确认标签或本轮assistant候选并保留不同来源；不要直接把本轮mask变成人工GT。
当前冻结 bank 未被修改。
